# 📚 BookFinder

BookFinder is a **React + Tailwind CSS** web app that lets you search books using the **Open Library API**, save favorites, and enjoy a clean, responsive UI.

---

## ✨ Features
- 🔍 Search by **Title, Author, or Subject**
- 📖 View book info (cover, title, author, year)
- ❤️ Add/Remove **Favorites** (stored in browser)
- 🌐 Detects when **offline**
- 📄 **Load more** pagination
- 🎨 Responsive UI with **Tailwind CSS**

---

## 🛠️ Tech Stack
- ⚛️ React (Vite)
- 🎨 Tailwind CSS
- 📡 Open Library API
